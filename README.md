Sports software for hockey, football, and basketball. Predictive modeling, simulations, dashboards, and games.

---

### [MultiSport Playoff Lab](https://multisport-elo-lab.streamlit.app/)

Elo ratings plus Monte Carlo simulation for NHL, NFL, and NBA. Set model parameters, run a grid search, and simulate the schedule and playoff bracket. Playoff odds and win distributions, model calibration, and an Excel export.

### [MultiSport Live Win Probability](https://github.com/elevation-edge-sports-data/multisport-live-win-probability)

Live in-game win probability for hockey, football, and basketball games.

### [Hockey Fast Break](https://elevation-edge-sports-data.github.io/hockey-fast-break/)

A 3D hockey game for web browser, built with React Three Fiber and a 60 Hz sim. Fast break versus CPU with pass, shot, deke, and hit, and a freestyle camera in live play and replay. Uniforms, arena, keyboard or gamepad, Classic and Wings control profiles.

### [Football Ground Attack](https://elevation-edge-sports-data.github.io/football-ground-attack/)

A 3D football game for web browser on one HTML5 canvas. Authored offense and defense playbooks, Game and Practice modes, keyboard or gamepad, and five control profiles. Uniforms, stadium, and a freestyle camera in live play and replay.

### [Playoff Elimination History](https://elevation-edge-sports-data.github.io/playoff-elimination-history/)

A map of every playoff elimination in the NHL (1918–2026), NFL (1966–2025), and NBA (1947–2026). Season-specific logos, arena locations, and a 2D or 3D camera.

### [NBA Win Models](https://github.com/elevation-edge-sports-data/nba-win-models/blob/main/nba_home_win_probability.ipynb)

Home team win probability models for the 2025-26 NBA season, using only information available before tipoff. Log5, logistic regression, random forest, and XGBoost, with chronological validation and calibration diagnostics.

### [NHL Team History](https://elevation-edge-sports-data.github.io/nhl-team-history/)

Interactive NHL dashboard with 100+ years of regular-season and playoff results, plus modern process stats (xGF%, CF%, FF%). Team or franchise view, a sortable table, and charts that combine regular-season, playoff, and process stats history.

### [Workout 100 App](https://github.com/elevation-edge-sports-data/workout-100-app)

Fitness ledger and on-device distance tracker. Exercises and walk miles roll into daily points totals. Data stays on the device until you export it.
